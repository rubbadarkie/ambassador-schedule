# Student Ambassador Posting Schedule

A simple webpage to manage and track the Microsoft Copilot Student Ambassador posting schedule across Singapore universities.

## What it does

- Lists all 30 student ambassadors with their assigned posting dates
- Runs from **14 April to 13 June 2026**, posting every 2 weekdays
- Lets you filter ambassadors by batch (Batch 1, 2, or 3)
- Shows a summary of key schedule stats at a glance

## Post requirements

Each ambassador is required to create and share a personal page that includes:

1. **About Me** — a personal introduction
2. **What I Love About Copilot** — their honest take on Microsoft Copilot
3. **My Copilot Use Case** — a real example of how they use it

Ambassadors are free to explore different designs, but the core message must remain aligned.

## Universities represented

NTU · NUS · SUTD · SIM · SUSS · SMU

## How to use

Just open `index.html` in any browser — no installation or dependencies needed. Use the batch filter buttons to view ambassadors by group.
